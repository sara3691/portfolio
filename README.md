# SaaS-Grade Portfolio CMS Platform

A fully dynamic, database-driven Portfolio CMS built with a modern stack. Manage your entire professional presence—content, styles, themes, and layouts—through a premium admin dashboard.

## 🚀 Tech Stack

- **Frontend & Admin**: Next.js (App Router), Tailwind CSS, Framer Motion, Zustand.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB (Atlas) with Mongoose.
- **Deployment**: Render (Backend), Netlify (Frontend/Admin).

## 📂 Project Structure

- `/backend`: Express API with dynamic CRUD controllers.
- `/frontend`: Public-facing portfolio with a dynamic rendering engine.
- `/admin`: Professional CMS dashboard with live editor and theme studio.

## ⚙️ Features

- **Dynamic Styling**: Change fonts and colors instantly via the admin panel.
- **Live Preview**: See your changes in real-time as you edit.
- **Section Management**: Reorder or hide sections (Hero, Projects, Skills) without code.
- **JWT Auth**: Secure admin access.

## 🛠 Setup

1. Clone the repository.
2. Install dependencies in each folder (`backend`, `frontend`, `admin`).
3. Set up environment variables as described in `.env.example` (or the provided walkthrough).
4. Run `npm run dev` in all folders.
